# SMART Architecture & Construction Co. Ltd

Marketing website for SMART Architecture & Construction Company Ltd — an architecture, civil
engineering, and construction consultancy based in Buea, Cameroon.

Built with React 19, Vite, Tailwind CSS, and GSAP.

## Development

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

Production output is written to `dist/`.

## Deployment

This project deploys to [Vercel](https://vercel.com) with zero configuration — it auto-detects the
Vite framework preset (build command `vite build`, output directory `dist`).
